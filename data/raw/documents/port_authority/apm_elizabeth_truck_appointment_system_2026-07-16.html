Truck Appointment System

TERMPoint includes features such as a Dashboard showing the status of your appointments, Import Container Watch-list, and the possibility to schedule both Import and Export Appointments simultaneously. A number of features are highlighted below.

Adding Driver Details

Assigning drivers to appointments will allow future trucker experience enhancements which will be communicated at a later date. The new Drivers tab will also allow you to view the truck driver and Safety Induction status to avoid turnaround at the Inbound gate.

- Driver is optional until 1 hour prior to the appointment slot start time.
- Driver can be changed until the end of the appointment slot.

TERMPoint Features

A quick summary of daily appointments by status. Drill down to appointments requiring attention.

Conveniently schedule appointment requests for imports, exports and empties via a single screen as TERMPoint prompts for the required information based on selection.


Monitor daily appointment status and use the Advanced Search to organize appointments for the day.

Easily track Import containers and receive notifications when containers are ready for appointment.

Users can now swap out one of the moves on a dual appointment as needed.

This can only be done if appoinments share the same time slot.
