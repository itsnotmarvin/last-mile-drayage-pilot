# Consumer prose review

Reviewer: implementation author/AI, not an independent human adjudicator.
Purpose: inspect the actual final answers, separately from successful tool schemas.
This is a bounded smoke batch, not the original experimental endpoint regrade.

The three initial responses and the final targeted regression were captured with
Claude's native Copy action, pasted into a separate plain-text TextEdit buffer,
saved, then copied into per-run files. Each run has its exact original prompt and
one attributed MCP event with full arguments, response and supporting assessment.
The ephemeral incognito chats do not provide durable conversation URLs.

## Initial frozen batch

All three used the assessment without an explicit MCP-use hint. The tool arguments
retained the exact supplied statement and whole-trip scope. No response issued
operational permission or equated a gross-weight comparison with a bridge result.
The candidate route stayed unconfirmed and missing destinations did not inherit
APM gate observations.

The access answer correctly said that absence from Appendix C establishes neither
permission nor prohibition. It retained the standard-truck, unrestricted-road and
direct-access qualifications. The underlying initial prepared explanation did not
include the return-to-network exception; that omission is recorded and was fixed
only after the frozen batch.

The annual-permit answer included the 90,000/38,000/56,400-pound retained table,
legal-dimension condition, transcript qualification, separate authority sources,
missing axle weights/spacings and non-exhaustive next checks. It omitted October 6,
2026 despite that date appearing in the source statement and prepared answer.
This is a presentation failure. It is not repaired by the fact that the tool result
was correct, and the final targeted regression did not retest date retention.

The axle answer retained 11,000/34,000/34,000 group context, a 79,000-pound gross
comparison, source links and the need for individual axle measurements and spacing.
The model supplied those three values to the legacy unclassified weight field;
the original renderer's label “Axle weights reported” was ambiguous. No individual
axle split was invented or evaluated. The final renderer explicitly labels such
values unclassified and not individual-axle measurements; only local tests validate
that specific final wording change.

## Final targeted regression

`final_missing_dimensions` used implementation
`2119d669ea51edaf12253e8d9a2adf5ea4c3a18f73bbe5c98cf8c9c88576254a` after restart.
The answer directly addressed the Appendix C question, retained its source URL and
locators, and included return to the National Network or New Jersey Access Network,
the next-terminal exception, and direct access between networks. It preserved the
reported broad prerequisites, partial approach, candidate-route status, source-date
limitations and unresolved conclusion.

The answer is a faithful observed access explanation for this prompt, but is still
a paraphrase of the prepared answer. None of the four raw final responses is
byte-identical to its prepared Markdown; punctuation and wording changed. The
strict tool instruction to display verbatim therefore is not a proven invariant.

No overall full-consumer-pass rate is asserted. Actual tool use and useful
explanations improved in these observations, while date retention, universal
invocation and arbitrary final-answer fidelity remain unproven. One exposure per
prompt and same-author review cannot support a causal research claim.
